# Speakery Privacy Policy Draft

Last updated: 2026-07-02

Speakery helps users practise English through lessons, listening, speaking, writing, vocabulary, social features, and AI feedback.

## Data We Collect

- Account data: email address, display name, username, profile details.
- Learning data: level, XP, streaks, lesson progress, answers, completion history.
- Social data: friend requests, friend lists, profile text.
- AI feedback data: submitted text or compact practice context, feature type, request metadata, response length.
- Audio/photo data: microphone recordings or profile images only when the user chooses to use those features.

## Why We Use Data

- To provide learning features and save progress.
- To generate AI feedback through protected backend endpoints.
- To operate social profile features.
- To improve safety, moderation, debugging, and product quality.
- To manage admin operations and audit logs.

## AI Processing

Speakery sends only the text and compact context needed for the selected AI feedback task. Provider API keys are kept on the backend, not in the mobile app.

## Data Sharing

Speakery may use Firebase and AI infrastructure providers to run the service. Speakery does not sell personal data.

## User Choices

Users can choose whether to use microphone, photo, and social features. Users can request account or data deletion through support.
